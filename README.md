# FanMap (Global Fan Map)

Interaktívna platforma vizualizujúca globálnu fanúšikovskú podporu pre športové zápasy.

Plná dokumentácia je v `docs/`:
- `docs/idea.md` — produktová idea, diferenciácia, riziká
- `docs/business-case.md` — cieľ, monetizácia, konkurencia
- `docs/tech-stack.md` — zvolený tech stack a zdôvodnenie
- `docs/decisions-log.md` — chronologický záznam rozhodnutí
- `docs/idea-original-chatgpt.md`, `docs/dev-prompt-chatgpt.md` — pôvodné needitované zdrojové materiály

Kód appky pribudne po dokončení nastavenia (Supabase, Mapbox, Vercel účty).
